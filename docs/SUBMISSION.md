# 下一站 · REDcowork 纯前端交付

这份交付从现有网站的前端源码整理而来，保留原有桌面界面和交互；已经移除运行时对原站后端的依赖。原线上网站未被覆盖或重新发布。

## 建议提交方式

1. 先把 `02_给REDcowork的复刻提示词.md` 的内容复制给制作工具。
2. 如果支持上传工程 ZIP，上传 `下一站_纯前端源码.zip`。ZIP 根目录就是 `index.html`，只有浏览器端代码和静态素材，不包含服务器、数据库、环境变量或安装依赖。
3. 如果只支持 HTML 文件，使用 `下一站_纯前端原型.html`。页面、脚本、样式、地图和图片都已内嵌；可直接双击打开。
4. 如果工具只接受图片和文字，提供提示词及 `预览图` 文件夹，并让它参照 HTML 的交互复刻。

不要再上传之前的完整网站代码包，也不要要求工具接入原站接口。完整项目中包含多人房间数据库、行程推荐服务和在线查询，这是上一版不符合“纯前端”要求的原因。

本次只针对你提供的“仅支持纯前端”限制处理。没有代为向 REDcowork 提交，也没有验证其当前上传大小或其他审核规则；若它提示文件过大，优先使用源码 ZIP，而不是体积更大的单文件 HTML。

## 如何体验

- 解压源码 ZIP 后打开 `index.html`；或者直接打开单文件 HTML。
- 首页可缩放和拖动地图、选择城市、设置省份偏好、随机抽城市、收藏候选。
- 「我的行程」预置一份长沙示例。可以修改时间线、添加安排、填写住宿、记录花费和查看历史。
- 「房间演示」预置一个含三位示例伙伴和三份方案的房间。可体验投票、偏好、方案比较、日历、清单、记账与最终方案流程。
- 所有修改只存在当前浏览器。不同网址、不同浏览器、不同设备之间不互通。隐私模式和浏览器限制可能影响保存。
- 重新体验初始状态可清除这个页面的站点存储。请先自行备份需要的文字行程；不要用此演示保存唯一一份重要资料。

## 哪些是真实可用，哪些是示例

| 功能 | 纯前端版本行为 |
| --- | --- |
| 地图拖动、缩放、点选与飞镖选城 | 浏览器本地运行；地图和城市数据随包提供 |
| 候选收藏、偏好、表单和导航 | 可操作，保存在本机 |
| 行程推荐 | 六个城市使用预置模板，其余城市为可编辑占位草稿；不会调用模型 |
| 行程编辑、费用记录、历史版本 | 本地保存，不提交给服务器 |
| 安安对话 | 按话题返回固定示例文案，不理解任意自由输入 |
| 旅行房间、投票、清单、日历、结算 | 本地数据模拟界面和流程，不是真实多人协作 |
| 邀请朋友 | 展示邀请票并复制演示文案；没有可跨设备加入的邀请链接 |
| 实时费用、酒店、交通与天气 | 没有查询能力；由使用者手动核实和填写 |
| 行程文字 / 只读快照 | 文字可复制。快照链接只有发布到可访问的静态网址后才能分享；本地文件路径不能发给别人使用 |

## 文件清单

- `下一站_纯前端源码.zip`：给制作工具的首选提交包。
- `下一站_纯前端原型.html`：内嵌素材的可交互单文件原型。
- `frontend/`：可编辑的 HTML、CSS、JavaScript 和本地素材。
- `02_给REDcowork的复刻提示词.md`：可直接复制的复刻要求。
- `03_需求与技术说明.md`：页面范围、技术边界和数据说明。
- `04_验证记录.md`：本次检查的范围和结果。
- `预览图/`：桌面界面截图。

素材来源见工程中的 `credits.html`。图片、地图和第三方脚本原有署名已保留；原站作者及第三方素材的相关权利不因导出而改变。
